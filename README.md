# Roddis Roofing Showcase

Create a premium, professional, human-made **one-page UK roofing website** for **Roddis Roofing** using **React + Vite + Tailwind CSS**.

Keep the project lightweight. No backend, database, login, CMS, extra pages or unnecessary libraries. Complete everything in one implementation.

**Business:**
Roddis Roofing
Family run roofing specialist you can trust.
Covering Nottingham, Nottinghamshire & Derbyshire.
Experts in roofing & lead-work.

Phone: +44 1332 417383
Email: [roddisroofing@gmail.com](mailto:roddisroofing@gmail.com)
Address: 213 Church Street, Derbyshire, UK, DE5 9TF
Instagram: https://www.instagram.com/roddisroofing

### Design

Make it look like a real established UK roofing company website: premium, trustworthy, clean and professional. Use dark charcoal, white/off-white and a subtle warm accent. Use quality roofing images. Avoid AI-looking effects, excessive gradients, excessive rounded cards and unnecessary animations.

### Final requirements

Make everything responsive on desktop, tablet and mobile.

Prioritize completing all sections over fancy features.

Do NOT add anything unnecessary.
Do NOT ask questions.
Do NOT leave TODOs.
Do NOT rebuild or repeat components unnecessarily.
Keep the code simple and lightweight.
